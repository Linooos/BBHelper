# BBHelper

**崩坏学园2（官服）日常清理助手**

</div>

## 项目介绍

一键跑完《崩坏学园2》官服当天的日常内容：领邮件、收使魔探险、清存在感每日任务、
刷体力、收尾领奖。由 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 驱动。

适用环境：**官服**、**MuMu 模拟器**、**1280×720 横屏**，游戏已登录且能正常进大厅。

按「**主号爱惜**」设计 —— 所有消耗资源、不可逆的操作**默认关闭**，需要你在界面上
显式打开才会执行。

## 目前功能

`日常清理` 按下面的顺序执行，每一步都能在界面上单独开关：

| 阶段 | 做什么 | 消耗 |
| --- | --- | --- |
| 启动 | 冷启动游戏、点掉启动弹窗（每日签到 / 游戏公告）、进大厅 | — |
| 邮件领取 | 点「一键领取」收附件 | — |
| 使魔探险 | 领已完成的探险奖励，并补满已接取数 | — |
| 使魔的爱 | 多元裂缝关卡，走「快捷战斗」 | 体力 30 |
| 世界那么大 | 虚轴之庭任意关卡，走「快捷战斗」 | 免费次数 |
| 战力补强 | 礼包商店买「**零时馈礼**」 | **免费**（标价 ×0） |
| 体力消耗 | 刷「喵王の福利」累计消耗体力，一次做完三条累计任务 | 体力（每次 10） |
| 共鸣之力 | 刷新共鸣屋商品 | 免费次数内不消耗 |
| 领取以上任务奖励 | 回存在感页收掉里程碑奖励 | — |

`体力消耗` 下面挂着几个子选项：

- **关卡来源** —— 预设关卡（目前只有「喵王の福利」）/ 自定义关卡（⬜ 未实现）
- **刷关次数**
- **体力目标** —— 180 / 200 / 300。会**折算成刷关次数**：读关卡详情页的
  「消耗体力 N」，用目标值除它。比如目标 300、喵王每次 10 体力 → 刷 30 次

默认关闭的消耗性选项：

- **共鸣之力** —— 免费刷新次数用完后会消耗「零时之种」，默认**关闭**
- **使用双倍券** —— 双倍消耗换双倍奖励，且是消耗品，默认**关闭**
- **不领取体力邮件** —— 体力溢出时领取是浪费，默认**不领取**

脚本只在能确认安全时才动手：共鸣屋刷新只认弹窗正文写着「免费刷新」的，其余一律
点「取消」；快捷战斗灰着（未解锁）时跳过并记为「未完成」；邮件页的「一键删除」
不在任何识别区域内。
