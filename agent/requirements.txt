# Agent 运行期依赖 —— **发布产物**用这份。
#
# `tools/setup_embed_python.py` 会把这份装进包里自带的那个绿色 python，
# 终端用户不需要自己装任何东西。
#
# ⚠️⚠️ 版本必须与**调用方**的 MaaFramework 版本一致，绝不能随手升级。
#
# 为什么：MaaFramework 的 Agent 协议带版本号，客户端与服务端对不上时
# AgentServer 会**直接拒连**，而且**不弹任何提示** —— 表现是「跑任务什么
# 都没发生」，只有 agent 子进程的 stdout 里一行 Protocol version mismatch。
# 2026-09-19/20 在这上面卡了很久，细节见 docs/zh_cn/develop/dev_loop.md §4.5。
#
# ── 两个调用方，两个版本，故意不同 ────────────────────────────────
#
#   发布产物（MFAAvalonia）      自带框架 5.13.1  →  本文件
#   开发 venv（VS Code 插件）    自带框架 5.12.2  →  requirements-dev.txt
#
# 两边各有各的 python（包内 embeddable / 项目 .venv），互不干扰 ——
# 这正是「把 python 打进包里」顺带解决掉的一个老麻烦。
#
# 升级 MFAAvalonia 之后**必须回来核对这里**：
#   跑一次日常，然后翻包里的 logs，搜 Protocol version mismatch。
#   它的 client 那一半印的就是新框架的版本号。
#
# 安装（一般不用手动跑，install.py 会调）：
#     python tools/setup_embed_python.py
